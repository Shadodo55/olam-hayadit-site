# עולם הידית והפרזול – אתר קטלוג

אתר הקטלוג של עולם הידית והפרזול (יד חרוצים 16, תלפיות, ירושלים).
האתר בבנייה, והמסמך הזה יתעדכן בסוף כל שלב.

## איך האתר עובד, בקצרה

- **הקוד** נמצא כאן, ב-GitHub, בריפו פרטי.
- **האירוח** הוא ב-Cloudflare, בחינם.
- **פרסום אוטומטי:** כל שינוי שנכנס לענף `main` עובר קודם בדיקות אוטומטיות. אם הבדיקות עוברות, הוא מתפרסם לבד באתר, תוך כמה דקות.
- **תוכן:** מוצרים, מחירים ושעות יעודכנו במערכת Sanity (משלב 3), בלי לגעת בקוד.

## הרצה מקומית (למפתחים)

צריך להתקין Node.js בגרסה 22 ומעלה. אחר כך:

```bash
npm install
npm run dev          # אתר מקומי בכתובת http://localhost:3000
npm run check        # בדיקות קוד (lint, טיפוסים, בדיקות יחידה)
npm run build        # בניית האתר הסטטי לתיקייה out
npm run test:e2e     # בדיקות דפדפן ונגישות (axe), אחרי build
```

במחשב Windows, אם PowerShell חוסם הרצת סקריפטים, משתמשים ב-`npm.cmd` במקום `npm`.

## משתני סביבה

ההגדרות נמצאות בקובץ `.env.example`. מעתיקים אותו לקובץ `.env.local` וממלאים ערכים.
סודות (מפתחות ו-tokens) לא נכנסים ל-git אף פעם.
